# s1-4: UTF-16 surrogate pairs disappear in the fallback

**Severity**: MEDIUM — emoji and some CJK characters are deleted from recovered documents
**Status**: In progress
**Branch**: — (default-branch mode)
**Commit**: pending

Source: Reviewer (generation): codex / gpt-6-astra / xhigh / frontier (owner-named pair)
Range: b5f958b..caf8a5e (slice 1), codex-cli 0.164.0, 2026-10-25 UTC.

## Evidence
`crates/cli/src/scrivener/parser/rtf_text.rs` `\u` handling: each `\uN` is
turned into a `char` on its own; a surrogate half fails `char::from_u32`
and is dropped, and its fallback is skipped too.

## Predicted observable failure
`before \u-10179 ?\u-8704 ? after` imports as `before  after`; the 😀 is
gone. (Pandoc itself also fails on surrogate pairs — two U+FFFD — so the
prepare path cannot do better than Pandoc here; noted as a known gap.)

## Approach
Hold a high surrogate until the next `\uN`; when it is a low surrogate,
combine and emit the character. A lone half emits U+FFFD so the loss is
visible rather than silent.

## Files changed
- `crates/cli/src/scrivener/parser/rtf_text.rs`

## Guard proof
`cargo test -p chikn-converter --lib -- surrogate_pairs_combine`:
`\u-10179 ?\u-8704 ?` → 😀; a lone high half → U+FFFD in place; a trailing
lone half → U+FFFD at the end. With pairing disabled (the high-surrogate
arm unreachable) the test fails (two U+FFFD); restored, it passes.

Repair: the same test gains a pair split by CRLF and one split by `\b`
(both → 😀), a lone half in a skipped destination (`body` only) and one in
a field result (`[�](u)`). With the lone-half check back on bare line ends
and off group close, the test fails; restored, it passes.

Second repair: the same test gains a half before a field
(`x�[label](u)y`), before a skipped group (`x�y`), before a
backslash-newline break (`x�` / blank / `y`) and across such a break (two
markers, never combined). With the group-open and break resolution removed
the test fails; restored, it passes.

Third repair: the same test gains a pair split by an ordinary group
(`x😀y`), by a `\b` group, inside a field result (`[😀](u)`), and a
backslash-newline in the fallback slot (`x😀y`). With resolution restored
at every `{` and the newline fallback consumption removed, the test fails;
restored, it passes; the suite is 68/68; clippy clean.
