# s3-5: Compile warnings never reach the writer

**Severity**: MEDIUM — writers cannot learn that links were removed or left unresolved
**Status**: Verified — accepted 2026-10-27 23:34 UTC
**Branch**: — (default-branch mode: one finding ↔ one commit on `master`)
**Commit**: `587e38f`; repair `dddd107` (transport) and `67c9ded` (display) after repair review 1; repair `22a852b` after repair review 2

## Evidence
`crates/core/src/core/compile.rs` `compile` discards the `CompileReport`; `crates/services/src/io.rs` `compile_project` calls it, and both shells call the service. A missing fragment, a refused footnote destination or a swallowed marker yields an ordinary successful export with no notice.

## Approach
Carry the warnings through the service, the desktop command, the web export response and the UI (shown after the export).

## Files changed
Declared before repair: `crates/services/src/io.rs`, `src-tauri/src/commands/io.rs`, `crates/web/src/commands.rs`, `crates/web/src/export.rs`, `ui/src/commands/io.ts`, the compile dialog, tests. Actual (per the repair review): `ui/src/commands/web.ts` also changed; `crates/web/src/commands.rs` did not. Repairs: `crates/web/src/{app,export,state}.rs`, `crates/web/tests/http.rs`, `ui/src/commands/web.ts`, `ui/src/test/compileWarnings.test.ts` (`dddd107`); `ui/src/components/compile/CompileDialog.tsx`, `ui/src/editor.css`, `ui/src/test/compileWeb.test.tsx` (`67c9ded`). Repair 3: `ui/src/components/compile/CompileDialog.tsx`, `ui/src/test/compileWeb.test.tsx`.

## Guard proof
`shows the server's compile warnings after a web export` (ui/src/test/compileWeb.test.tsx) fails with the warnings toast disabled; `warnings_travel_as_a_percent_encoded_json_array` (crates/web/src/export.rs) fails with the percent-encoding removed; both restored and green.

Repair `22a852b`: Cancel, the close control, the overlay and Escape do nothing while compiling (`dismiss` checks `compiling`; `finish` still closes through `close`). `compileWeb.test.tsx` "cannot be dismissed while an export runs, so its warnings are never lost" (export left pending, all three dismissal routes clicked, then settled with one warning → list shown, `onClose` only on Done) fails with the dismissal unguarded, 1 failed; restored → 5 passed, lint and build green.

Restored → web 14+29+3 tests, UI 7 tests, lint, build, clippy green. (CI has no pandoc: the http test takes its 422 branch there; the full path ran locally.)

Repair `67c9ded` (display): `compileWeb.test.tsx` "keeps every warning on screen until the writer is done" (40 warnings all listed in a scrollable panel, count shown, no toast, dialog open until Done) fails with the dialog closing regardless (`finish` → `close()`), 1 failed; restored → 4 passed, lint, build green.
