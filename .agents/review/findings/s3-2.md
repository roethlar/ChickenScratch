## Evidence
`ui/src/components/editor/ImageNode.ts` (`renderHTML` of `src`) and `ui/src/platform.ts` `resolveAssetUrl`. For `![Picture](<research/my image.png>)` the attribute holds the Markdown URI `research/my%20image.png`; the resolver encodes it again into `path=research%2Fmy%2520image.png`, the route decodes once and the service looks for the literal file `my%20image.png`.

## Approach
Keep the Markdown URI in the attribute for serialisation; decode it once (as a local path) before building the shell's asset URL.
