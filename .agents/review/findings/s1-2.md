## Evidence
`crates/cli/src/scrivener/parser/rtf_text.rs`: field text is emitted only
on the closing `}` of the `\field` group. A rejected document that ends
inside `{\field…{\fldrslt essential text` never closes, so the result is
never emitted.

## Predicted observable failure
Truncated RTF `{\rtf1 before {\field{\*\fldinst{HYPERLINK "u"}}{\fldrslt essential text`
imports as `before` only.

## Approach
At end of input, unwind every open field: emit its result text (and the
link when a complete target was read) into the enclosing sink.

## Files changed
- `crates/cli/src/scrivener/parser/rtf_text.rs`

## Guard proof
`cargo test -p chikn-converter --lib -- truncated_field_keeps_its_text`:
a document cut off inside `{\fldrslt essential text` yields
`before [essential text](scrivcmt://X)`, and one cut off before the
result yields `before <scrivcmt://X>`. With the end-of-input unwind
removed the test fails (`before` only); restored, it passes.
